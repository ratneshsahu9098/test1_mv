# 🚗 MV Tax Dashboard

Modern Vehicle Tax Reminder Dashboard built using React + Flask.

---

## ✨ Features

- Vehicle Management
- Expiry Tracking
- Dashboard Analytics
- User Management
- Deleted Vehicle Recovery
- JWT Authentication
- Export Vehicle Data to Excel
- Role Based Access
- Responsive Admin Panel

---

## 🛠 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios

### Backend
- Flask
- Flask-JWT-Extended
- SQLite
- Pandas
- OpenPyXL

---

## ⚙️ Backend Setup

```bash
pip install -r requirements.txt
python dashboard.py
```

---

## ⚙️ Frontend Setup

```bash
cd mv-tax-frontend
npm install
npm run dev
```
